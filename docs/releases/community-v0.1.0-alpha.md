# PCL NE Plugin IDE Community Edition 0.1.0-alpha

This is the first M0–M1 Community alpha release, based on Code - OSS 1.133.0.

## Included

- Community-only identity, data directories, protocol, icons, and modern UI
- 26-entry built-in extension allowlist; Copilot/Agent/Chat product surfaces removed
- Local Extensions management without a configured Marketplace
- PCL project create/open/new-file commands and focused Explorer defaults
- Public PNPSDK 0.2.5 restore, Analyzer, build, development OpenPGP signing, package, and validation workflow
- Roslyn language features through pinned `csharp-ls 0.26.0`
- `plugin.json` and `.nplug` schemas plus the Hello PCL .NET 10 fixture
- Persistent Trusted Folder state and corrected built-in API version compatibility

## Assets

- `PCL-NE-Plugin-IDE-Community-0.1.0-alpha-win32-x64.zip` — portable Windows x64 application
- matching `.sha256` file
- `com.pcln.hello-pcl-0.1.0.pnp` — verified M1 example package

This is an unsigned alpha build. Production signing, an installer, automatic updates, Sidecar runtime/debug, and Registry publishing remain later milestones.
